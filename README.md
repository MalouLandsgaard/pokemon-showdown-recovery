# Architecture Recovery Project
## Overview
This project was part of a university course focused on Software Architecture and Analysis. Our objective was to perform an architecture recovery of a large-scale open-source software repository to better understand its structure, evolution, and design decisions.

## Key Contributions
Automated Diagramming: I introduced automated generation of architecture diagrams using tools such as [e.g., Graphviz, PlantUML, or Mermaid] to visualize module dependencies and system structure. This helped reduce manual effort and improved clarity during analysis.

GitHub History Analysis: I performed a comprehensive analysis of the repository's Git history to identify major architectural changes, active components, and contributions over time.

Component Mapping: We decomposed the system into logical components and mapped out key architectural layers and their responsibilities.

Tooling & Scripts: Developed custom scripts to extract and process structural data from the codebase and visualize relationships between modules.
